# Figure sources

The diagrams are editable TikZ sources and remain vector graphics in the PDF.
The empirical plots are generated by `../scripts/make_figures.py` from the
included evidence snapshot and training CSV. No generative image model is used.

`move_scores.tex` adapts the complete move-score figure from `paper/main.tex`
to the journal palette and notation. It shows the duplicate-label decision,
decoded alignment, marking sequence, and every entry of the synchronous, model,
and auxiliary log scores from `data/evidence.json`.

`implementation_screenshots.tex` includes `lara-tool-live-run.png` and
`lara-tool-trace-inspector.png`, copied unchanged from `paper/`. Each screenshot
uses a `figure*` with `[!t]` placement and the MDPI full-page figure width. Both
are mentioned in the surrounding implementation text and included in the
submission archive. All future figures should likewise use `figure*` with
`[!t]` or `[!b]` placement.
