# Figure sources

The diagrams are editable TikZ sources and remain vector graphics in the PDF.
The empirical plots are generated by `../scripts/make_figures.py` from the
included evidence snapshot and training CSV. No generative image model is used.

For screenshots supplied later, add `implementation_screenshots.tex` here with
`figure*` environments with `[!t]` or `[!b]` placement and `\includegraphics`
commands. Mention every screenshot in the surrounding text. The implementation
section loads that file automatically when present. There are no empty screenshot
boxes or invented screenshots in the current PDF. Recommended views are the Live
Run evidence columns and the Trace Inspector's marking replay and move comparison.
